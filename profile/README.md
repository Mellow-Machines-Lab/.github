# Mellow Machines Lab

Open hardware and software that keeps you company while your agents work.

<p align="center">
  <img src="https://raw.githubusercontent.com/Mellow-Machines-Lab/buddygotchi/main/documentation/media/boop.gif" width="440" alt="Boop's face on its board: napping, working along, an amber 'Claude needs you' sign, then a trophy for a big finish">
</p>

| | Project | What it is |
| --- | --- | --- |
| 🟨 | **[buddygotchi](https://github.com/Mellow-Machines-Lab/buddygotchi)** | Boop, a little creature for your desk that keeps an eye on your AI coding agents. A Mac app and a cheap ESP32 board |
| 🪝 | **[AgentHooks](https://github.com/Mellow-Machines-Lab/AgentHooks)** | Tells you which of your coding agents needs you. A Swift library and command line for Claude Code and Codex hooks |
| 🧠 | **[MellowHarness](https://github.com/Mellow-Machines-Lab/MellowHarness)** | Give anything a personality with Markdown and multiple choice. A Swift library |

each project's `CONTRIBUTING.md` says how.
